# 영어 학습 복습 앱 — 설계 문서 (1단계)

작성일: 2026-09-10

## 1. 목적

회사 영어 수업의 학습자료(문장·단어·주제)를 듀오링고처럼 재미있고 반복적으로
복습하기 위한 개인용 웹앱. 핵심 목표는 **"내가 자주 틀리는 단어·문장을 다양한
연습 형태로 반복 노출"** 시키는 것.

사용자는 1명(앱 소유자 본인), 단일 기기 사용을 전제로 한다.

## 2. 전체 방향과 단계

전체 비전은 크게 5개 덩어리로 구성되며, 단계적으로 구현한다.

1. 학습자료 입력 & 정리
2. 연습 콘텐츠 (5종)
3. 복습 엔진 (약한 항목 반복)
4. 게이미피케이션 (스트릭·보석·프리즈)
5. AI 화상통화 + 오답 자동 캐치

- **1단계 (본 문서 범위)**: 1~4번. AI(LLM) 키 없이, 서버 없이, 브라우저 내장
  기능만으로 무료 동작.
- **2단계 (이후)**: LLM 키를 붙여 자료 자동 분석(문장·단어 추출), 작문 채점,
  간이 AI 대화.
- **3단계 (이후)**: 대화 기억·오답(문법/발음) 캐치 → 복습 엔진 연동, 원하면
  실시간 음성 API.

2·3단계 기능은 1단계의 복습 엔진 큐에 항목을 "추가"하기만 하면 자연스럽게
연동되도록 1단계를 설계한다.

## 3. 확정된 결정 사항

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹앱 (브라우저). 서버·로그인 없음 |
| 데이터 저장 | 브라우저 IndexedDB (로컬, 기기 밖으로 안 나감) |
| 주 브라우저 | Chrome / Edge (Web Speech API 완전 지원) |
| 스트릭 "하루 완료" 기준 | 학습 세션 1개 완료 |
| 연습 방향 | 영→한 / 한→영 양방향 섞기 |
| 자료 입력 | 타이핑/붙여넣기 + 파일 업로드(txt/docx/PDF/이미지) |
| AI/비용 | 1단계는 키 없음. 음성은 브라우저 내장 기능(무료) |

## 4. 아키텍처

**순수 클라이언트 사이드 웹앱 (서버 없음).**

- Vite + React + TypeScript 단일 페이지 앱
- 상태 관리: Zustand (경량 스토어) + IndexedDB 영속화
- 라우팅: React Router
- 스타일: Tailwind CSS (듀오링고풍 밝고 둥근 UI)
- 음성: Web Speech API
  - `SpeechSynthesis` (TTS, 읽어주기)
  - `SpeechRecognition` (STT, 말하기 채점) — Chrome/Edge 기준
- 파일 텍스트 추출 (모두 브라우저 내에서 처리):
  - `.txt`: FileReader
  - `.docx`: mammoth.js
  - 텍스트 PDF: pdf.js
  - 이미지/스캔 PDF: tesseract.js (OCR, WASM)

모든 파싱·저장·음성 처리가 클라이언트에서 일어나며 네트워크 요청이 없다.
정적 파일로 배포 가능(또는 `npm run dev` 로컬 실행).

### 브라우저 호환 주의
`SpeechRecognition`(말하기 채점)은 Chrome/Edge에서 안정적이며 Safari/Firefox는
지원이 약하다. 음성인식 미지원 브라우저에서는 "말하기" 유형을 자동으로
"쓰기/선택" 유형으로 대체(fallback)하고 안내 문구를 표시한다.

## 5. 데이터 모델 (IndexedDB)

```
Deck        { id, name, createdAt }
Word        { id, deckId, english, meaning, exampleSentenceId?,
              box (1~5), dueDate, stats { seen, correct, wrong } }
Sentence    { id, deckId, text, translation?,
              box (1~5), dueDate, stats { seen, correct, wrong } }
Profile     { streakCount, lastStudyDate, gems, freezeCount,
              dailyGoalSessions (=1), history: [{ date, completed }] }
```

- `box`, `dueDate`, `stats` 는 항목별로 복습 엔진이 관리한다.
- 새 항목은 `box=1`, `dueDate=오늘`로 시작한다.

## 6. 화면 구성

### 6.1 홈 (대시보드)
- 상단 상태바: 🔥 스트릭 일수 / 💎 보석 / 🧊 프리즈 개수
- "오늘의 목표" 진행 표시 + [오늘의 학습 시작] 버튼
- [복습하기] — 약한(box 낮은/복습일 도래) 항목만 모아 세션 구성
- 내 자료(덱) 목록 (덱별 단어/문장 개수)
- [+ 자료 추가] / [🛒 상점]

### 6.2 자료 추가
- 탭: `[타이핑/붙여넣기] | [파일 업로드]`
- 파일 업로드 시: 텍스트 추출 → 편집 가능한 입력창에 자동 채움
- 정해진 형식으로 항목 정리:
  - 단어: `영단어 = 뜻` (한 줄에 하나)
  - 문장: 한 줄에 하나 (선택적으로 `영문 | 번역`)
- 미리보기에서 파싱된 단어/문장 확인 후 저장

### 6.3 학습 세션 (레슨)
- 카드 10~15개가 연속으로 출제되는 흐름, 상단 진행 막대
- 여러 연습 유형이 섞여서 등장 (복습 엔진이 항목·유형 선택)
- 종료 시 결과 화면: 정답 수, 획득 💎, 스트릭 🔥 갱신, 틀린 항목 요약

### 6.4 상점
- 보석으로 🧊 프리즈 아이템 구매 (기타 아이템은 이후 확장)

## 7. 연습 유형 (5종, 모두 키 없이 무료)

| 유형 | 방식 | 기술 |
|---|---|---|
| 단어 짝짓기 | 영단어 ↔ 뜻 잇기 | 없음 |
| 단어 게임 | 4지선다 / 제한시간 맞추기 | 없음 |
| 단어 말하기 | 단어 제시 → 마이크 발음 → 인식 비교 | STT |
| 문장 따라하기 | 문장 읽어줌 → 따라 말하기 → 비교 | TTS + STT |
| 문장 쓰기(받아쓰기) | 문장 읽어줌 → 타이핑 → 비교 | TTS |

- 양방향: 단어/문장 문제는 영→한, 한→영이 섞여 출제된다.
- 채점은 정규화 후 비교(대소문자·문장부호·공백 무시, 발음 인식은 근사 일치 허용).

## 8. 복습 엔진 (핵심)

**라이트너(Leitner) 박스 방식.**

- 모든 단어·문장은 `box` 1~5 를 가진다.
- **정답** → `box + 1`, `dueDate` = 오늘 + 간격(box별: 0, 1, 2, 4, 7일)
- **오답** → `box = 1`, `dueDate` = 오늘 (같은/다음 세션에 재출제)
- 세션 구성 시 우선순위:
  1. `dueDate <= 오늘` 인 항목
  2. `box` 낮은 순 (= 많이 틀리는 항목)
  3. 신규 항목을 소량씩 섞어 도입
- 뽑힌 항목을 여러 연습 유형에 분배해 "같은 항목을 다양한 형태로" 반복 노출.

향후 AI가 잡아낸 문법·발음 오답도 동일한 큐(항목의 box를 낮추거나 신규 항목
추가)로 넣기만 하면 자동 연동된다.

## 9. 게이미피케이션

### 스트릭 🔥
- 하루에 세션 1개 완료 시 연속일 유지.
- 학습을 건너뛴 날 발생 시:
  - 🧊 프리즈 보유 → 1개 자동 소모, 스트릭 유지
  - 보유 없음 → 스트릭 리셋
- 판정 로직은 `lastStudyDate`와 오늘 날짜 차이로 계산. 빠진 날 수만큼 프리즈를
  소모하며, 프리즈가 모자라면 리셋.

### 보석 💎
- 세션 완료 시 지급 (기본 + 완벽 보너스 + 스트릭 마일스톤 보너스)

### 프리즈 🧊 (얼음)
- 상점에서 보석으로 구매.
- **보유 개수만큼 빠진 날을 메워 스트릭을 보호**한다.
- 보유 상한을 둔다(예: 최대 2~3개, 값은 구현 시 확정).

## 10. 1단계 범위 밖 (명시적으로 제외)

- LLM 기반 자료 자동 분석/구조화 (2단계)
- 작문 채점, AI 대화/화상통화 (2·3단계)
- 대화 기억·오답 자동 캐치 (3단계)
- 다중 기기 동기화·계정·클라우드 (필요 시 이후)
- 실시간 음성 API (선택적, 이후)

## 11. 성공 기준 (1단계)

- 자료를 타이핑 또는 파일로 넣어 단어·문장 항목을 만들 수 있다.
- 5종 연습이 세션으로 섞여 출제되고, 음성(읽어주기/말하기)이 Chrome에서 동작한다.
- 틀린 항목이 복습 엔진에 의해 이후 세션에 다시, 다양한 형태로 등장한다.
- 세션 완료로 보석을 얻고, 스트릭이 오르며, 상점에서 프리즈를 사서 스트릭을
  보호할 수 있다.
- 모든 데이터가 브라우저에 저장되어 새로고침/재방문 후에도 유지된다.
